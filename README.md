# LinkIt – מנהל קבצים עם קיצורי דרך (אנדרואיד)

מנהל קבצים קל, ללא הרשאת אינטרנט, עם יצירת קיצורי דרך למסך הבית.

## חדש בגרסה 3.0
- **מצב כהה אוטומטי** (לפי הגדרות המערכת) וצבעים מסודרים
- **כפתור + צף** ליצירה מהירה (תיקייה, קובץ, קיצורים)
- **סל מחזור:** מחיקה בטוחה עם שחזור, ניקוי אוטומטי אחרי 30 יום (אפשר לכבות בתפריט)
- **סינון לפי סוג:** תמונות, סרטונים, שמע, מסמכים, ארכיונים, APK
- **קבצים אחרונים** ו**קבצים גדולים** (בתיקייה הנוכחית ותחתיה)
- **ניתוח אחסון:** כמה מקום תופס כל סוג קובץ, כולל אחוזים ושטח פנוי
- שכפול, העתקת נתיב ללוח, הפיכת בחירה, גודל הנבחרים בכותרת, SHA-256 במאפיינים
- הוספת התיקייה הנוכחית למועדפים / למסך הבית, שטח פנוי בשורת המצב

## יכולות
- גלישה בזיכרון הפנימי ובכרטיס SD, פירורי לחם (breadcrumbs) לניווט מהיר
- העתקה, גזירה, הדבקה, מחיקה, שינוי שם, תיקייה/קובץ חדשים
- בחירה מרובה (לחיצה ארוכה), שיתוף, דחיסה ל-ZIP וחילוץ
- חיפוש מהיר בתיקייה; Enter מחפש גם בתתי-תיקיות
- מיון לפי שם / תאריך / גודל / סוג, הצגת קבצים נסתרים, מאפיינים
- **קיצורי דרך למסך הבית** לכל קובץ או תיקייה (תיקייה נפתחת בתוך האפליקציה), וגם לקישורים ולאפליקציות
- **קבצי קיצור דרך (כמו בווינדוס):** יוצרים קיצור כקובץ אמיתי (`.lnkit`) עם חץ על האייקון, גוזרים/מעתיקים ומדביקים אותו לכל תיקייה. לחיצה עליו פותחת את היעד
- **הדבק כקיצור דרך:** מעתיקים פריט, נכנסים לתיקייה אחרת ובוחרים ⋮ ← הדבק כקיצור דרך
- **שילוב עם מנהלי קבצים אחרים:** LinkIt מופיע בתפריט "שתף" (גם לקישורים מהדפדפן), וקבצי `.lnkit` נפתחים מכל מנהל קבצים
- תמונות ממוזערות לתמונות וסרטונים, "פתח באמצעות", "פתח מיקום יעד", שטח פנוי בכל אחסון
- **פתיחה במנהל הקבצים שלך:** כשפותחים קובץ `.lnkit` (או קיצור במסך הבית) שמצביע לתיקייה, התיקייה נפתחת במנהל הקבצים שבו אתה משתמש, ו-LinkIt לא מופיע בכלל. אפשר לשנות בתפריט ⋮
- **מועדפים** באפליקציה; ארבעת הראשונים מופיעים גם בלחיצה ארוכה על אייקון האפליקציה

## בנייה דרך GitHub
1. צור repository חדש בגיטהב והעלה אליו את כל תוכן התיקייה (כולל `.github`).
2. עבור ללשונית **Actions** - הבנייה תתחיל אוטומטית (או ידנית: Build APK ← Run workflow).
3. בסיום, היכנס להרצה ← **Artifacts** ← הורד את `LinkIt-APK`.
4. חלץ את ה-APK, העבר לטלפון והתקן (יש לאשר התקנה ממקורות לא ידועים).

## שימוש
בהפעלה הראשונה יש לאשר גישה לקבצים. לחיצה ארוכה על פריט מפעילה בחירה, ומשם אפשר ליצור קיצור למסך הבית או להוסיף למועדפים. תפריט ⋮ מכיל מקומות, מועדפים, חדש, מיון ועוד.
