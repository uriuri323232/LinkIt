# LinkIt – מנהל קבצים עם קיצורי דרך (אנדרואיד)

מנהל קבצים קל, ללא הרשאת אינטרנט, עם יצירת קיצורי דרך למסך הבית.

## יכולות
- גלישה בזיכרון הפנימי ובכרטיס SD, פירורי לחם (breadcrumbs) לניווט מהיר
- העתקה, גזירה, הדבקה, מחיקה, שינוי שם, תיקייה/קובץ חדשים
- בחירה מרובה (לחיצה ארוכה), שיתוף, דחיסה ל-ZIP וחילוץ
- חיפוש מהיר בתיקייה; Enter מחפש גם בתתי-תיקיות
- מיון לפי שם / תאריך / גודל / סוג, הצגת קבצים נסתרים, מאפיינים
- **קיצורי דרך למסך הבית** לכל קובץ או תיקייה (תיקייה נפתחת בתוך האפליקציה), וגם לקישורים ולאפליקציות
- **מועדפים** באפליקציה; ארבעת הראשונים מופיעים גם בלחיצה ארוכה על אייקון האפליקציה

## בנייה דרך GitHub
1. צור repository חדש בגיטהב והעלה אליו את כל תוכן התיקייה (כולל `.github`).
2. עבור ללשונית **Actions** - הבנייה תתחיל אוטומטית (או ידנית: Build APK ← Run workflow).
3. בסיום, היכנס להרצה ← **Artifacts** ← הורד את `LinkIt-APK`.
4. חלץ את ה-APK, העבר לטלפון והתקן (יש לאשר התקנה ממקורות לא ידועים).

## שימוש
בהפעלה הראשונה יש לאשר גישה לקבצים. לחיצה ארוכה על פריט מפעילה בחירה, ומשם אפשר ליצור קיצור למסך הבית או להוסיף למועדפים. תפריט ⋮ מכיל מקומות, מועדפים, חדש, מיון ועוד.
