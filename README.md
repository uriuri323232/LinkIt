# LinkIt 5.0 - קיצורי דרך + מנהל קבצים

**פותח על ידי יהודי לא פשוט @מתמחים טופ**

אפליקציה ללא הרשאת אינטרנט (עובדת אופליין לחלוטין).

## חדש ב-5.0
- **הפעלה בלחיצה אחת:** לחיצה על קיצור ברשימה מפעילה אותו מיד. כל שאר הפעולות בלחיצה ארוכה או ב-⋮.
- **⭐ מועדפים:** שורת הפעלה מהירה עם אייקונים בראש המסך. מועדפים גם מופיעים ראשונים ברשימה ובלחיצה ארוכה על אייקון האפליקציה.
- **קטגוריות (#):** כל קיצור יכול לקבל קטגוריה, עם תגי סינון ברשימה וחיפוש גם לפי קטגוריה.
- **באנר קישור מהלוח:** כשמעתיקים קישור באפליקציה אחרת, מופיע באנר ליצירת קיצור בלחיצה אחת.
- **פעולות חדשות:** העתקת היעד ללוח ושיתוף (לקישור, טקסט, מספר, כתובת).
- **מידע ברשימה:** "לפני 3 ימים" לשימוש אחרון, והקטגוריה בכל שורה.
- ללא שום ספרייה חדשה ובלי הרשאות חדשות, כך שהאפליקציה נשארת קלה.

## חדש ב-4.6
- **סמל קיצור דרך גם באפליקציות אחרות:** בתוך מנהלי קבצים ובוחרי קבצים (ספק האחסון "LinkIt - קיצורים") כל קיצור מוצג עם תמונה ממוזערת של האייקון שלו וחץ קיצור, ועם סמל קיצור כברירת מחדל. בחלון "פתח באמצעות" קובץ `.linkit` מופיע עם סמל הקיצור.
- חץ הקיצור פעיל כברירת מחדל בקיצורים חדשים (אפשר לכבות לכל קיצור).
- ספק האחסון יציב יותר מול מנהלי קבצים שמבקשים רק חלק מהעמודות.
- **קל במשקל:** כיווץ קוד ומשאבים (R8) גם בבנייה של GitHub, בלי ספריות חיצוניות ובלי הרשאת אינטרנט. הסמל החדש הוא וקטור קטן.

## חדש ב-4.5
- קרדיט קטן וקבוע בתחתית המסך (וכרטיס בחלון אודות). כפתורי הכותרת עוצבו כעיגולים, ולכרטיסי הקיצורים נוסף מסגור עדין.
- כפתור "צור קיצור ראשון" במצב ריק; לחיצה ארוכה על קיצור מפעילה אותו מיד.

## חדש ב-4.3
- תפריט ⋮: "צור קיצור מהלוח" (קישור או טקסט שהועתק) ו"אודות".

## תיקון: אייקון כפול במסך הבית
מנהל הקבצים הוגדר בטעות כנקודת כניסה שנייה (LAUNCHER), ולכן האפליקציה הופיעה פעמיים. כעת יש אייקון אחד; מנהל הקבצים נפתח מכפתור 📂 במסך הראשי או מלחיצה ארוכה על האייקון.

## מה חדש בגרסה 4
- **בלי "קפיצה" בין מנהלי קבצים**: קובץ קיצור (`.linkit`) שנפתח מתוך מנהל קבצים פותח את התיקייה באותו מנהל קבצים
  שממנו לחצת (LinkIt מזהה את האפליקציה שהפעילה אותו). אם המנהל לא תומך בניווט ישיר, אתה נשאר בו והנתיב מועתק ללוח.
- **"מנהל הקבצים המועדף שלי"** (תפריט ⋮): קיצורי תיקיות שלא הוגדר להם מנהל מסוים ייפתחו בו.
- **שם הקיצור = שם היעד** (התיקייה / הקובץ / האפליקציה), בלי "קיצור דרך" ובלי תוספות. קובץ הקיצור נשמר בשם
  `<שם התיקייה>.linkit`, ובמנהל הקבצים של LinkIt הסיומת מוסתרת.
- **חץ קיצור על האייקון** (כמו בווינדוס), ניתן להפעלה/כיבוי לכל קיצור.
- הפרויקט מוגדר כך שהוא **מתעלם מכל קבצים ישנים** שנשארו ב-`app/src/main`, ולכן הבנייה לא נשברת בגללם.

## LinkIt קבצים (מנהל קבצים מובנה)

## שימוש כתוסף למנהלי קבצים אחרים
- קבצי `.linkit` נפתחים מכל מנהל קבצים.
- ספק אחסון "LinkIt - קיצורים" בתוך מנהלי קבצים שתומכים בכך.
- LinkIt מופיע ב"פתח באמצעות" (תיקיות) וב"שתף" (קבצים, קישורים, טקסט).

## בנייה דרך GitHub
1. העלה את כל תוכן התיקייה ל-repository (כולל `.github`).
2. מומלץ למחוק את התיקייה הישנה `app/src/main` (אינה בשימוש יותר).
3. לשונית **Actions** ← הבנייה מתחילה אוטומטית. בסיום: **Artifacts** ← `LinkIt-APK`.

דרישות: אנדרואיד 8.0 ומעלה.
