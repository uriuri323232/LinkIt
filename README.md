# קיצורי דרך (LNK) לאנדרואיד

אפליקציה קטנה ללא הרשאת אינטרנט, שיוצרת קיצורי דרך במסך הבית ל:
קישורים, קבצים, תיקיות ואפליקציות.

## בנייה דרך GitHub
1. צור repository חדש בגיטהב והעלה אליו את כל תוכן התיקייה (כולל `.github`).
2. עבור ללשונית **Actions** - הבנייה תתחיל אוטומטית (או הפעל ידנית: Build APK ← Run workflow).
3. בסיום, היכנס להרצה ← **Artifacts** ← הורד את `LnkShortcuts-APK`.
4. חלץ את ה-APK, העבר לטלפון והתקן (יש לאשר התקנה ממקורות לא ידועים).

## שימוש
פתח את האפליקציה, בחר סוג קיצור, ואשר את ההוספה למסך הבית.
