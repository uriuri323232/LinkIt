# LinkIt 4.0 - קיצורי דרך + מנהל קבצים

אפליקציה ללא הרשאת אינטרנט (עובדת אופליין לחלוטין).

## מה חדש בגרסה 4
- **בלי "קפיצה" בין מנהלי קבצים**: קובץ קיצור (`.linkit`) שנפתח מתוך מנהל קבצים פותח את התיקייה באותו מנהל קבצים
  שממנו לחצת (LinkIt מזהה את האפליקציה שהפעילה אותו). אם המנהל לא תומך בניווט ישיר, אתה נשאר בו והנתיב מועתק ללוח.
- **"מנהל הקבצים המועדף שלי"** (תפריט ⋮): קיצורי תיקיות שלא הוגדר להם מנהל מסוים ייפתחו בו.
- **שם הקיצור = שם היעד** (התיקייה / הקובץ / האפליקציה), בלי "קיצור דרך" ובלי תוספות. קובץ הקיצור נשמר בשם
  `<שם התיקייה>.linkit`, ובמנהל הקבצים של LinkIt הסיומת מוסתרת.
- **חץ קיצור על האייקון** (כמו בווינדוס), ניתן להפעלה/כיבוי לכל קיצור.
- הפרויקט מוגדר כך שהוא **מתעלם מכל קבצים ישנים** שנשארו ב-`app/src/main`, ולכן הבנייה לא נשברת בגללם.

## קיצורים (14 סוגים)
קישור · קובץ · תיקייה · אפליקציה · חיוג · SMS · וואטסאפ · אימייל · מיקום · טקסט · הגדרות מכשיר · פנס · טיימר · תפריט

## במה לפתוח תיקייה (לכל קיצור)
אוטומטי (ברירת מחדל) · LinkIt מובנה · מנהל קבצים ספציפי · בחירה בכל פעם · ברירת מחדל של המערכת

## LinkIt קבצים (מנהל קבצים מובנה)
דפדוף, העתקה/גזירה/הדבקה, שינוי שם, מחיקה, תיקייה חדשה, חיפוש, מיון, שיתוף, ויצירת קיצורים מכל קובץ או תיקייה.

## שימוש כתוסף למנהלי קבצים אחרים
- קבצי `.linkit` נפתחים מכל מנהל קבצים.
- ספק אחסון "LinkIt - קיצורים" בתוך מנהלי קבצים שתומכים בכך.
- LinkIt מופיע ב"פתח באמצעות" (תיקיות) וב"שתף" (קבצים, קישורים, טקסט).

## בנייה דרך GitHub
1. העלה את כל תוכן התיקייה ל-repository (כולל `.github`).
2. מומלץ למחוק את התיקייה הישנה `app/src/main` (אינה בשימוש יותר).
3. לשונית **Actions** ← הבנייה מתחילה אוטומטית. בסיום: **Artifacts** ← `LinkIt-APK`.

דרישות: אנדרואיד 8.0 ומעלה.
