# LinkIt - קיצורי דרך + מנהל קבצים לאנדרואיד

אפליקציה ללא הרשאת אינטרנט (עובדת אופליין לחלוטין).

## קיצורים (14 סוגים)
קישור · קובץ · תיקייה · אפליקציה · חיוג · SMS · וואטסאפ · אימייל · מיקום · טקסט · הגדרות מכשיר · פנס · טיימר · תפריט

## פתרון ה"קפיצה" בין מנהלי קבצים
לכל קיצור תיקייה/קובץ/קישור אפשר לקבוע **במה לפתוח אותו**:
- **LinkIt (מובנה)** - נפתח במנהל הקבצים של LinkIt, בלי לעבור לאפליקציה אחרת (ברירת המחדל לתיקיות).
- **מנהל קבצים ספציפי** - רשימת מנהלי הקבצים המותקנים אצלך (Solid Explorer, MiXplorer, Material Files, Amaze,
  Samsung My Files, Google Files ועוד). הקיצור נפתח רק בו, גם אם יש מנהלים אחרים.
- **בחירה בכל פעם** / **ברירת מחדל של המערכת**.

כל מנהל קבצים תומך בשיטת פתיחה אחרת, ולכן LinkIt מנסה אוטומטית כמה שיטות (מזהה מסמך, נתיב, BROWSE ועוד).
אם מנהל מסוים לא תומך בפתיחה ישירה, הוא נפתח והנתיב מועתק ללוח.

## LinkIt קבצים (מנהל קבצים מובנה)
דפדוף באחסון הפנימי וכרטיסי SD, פתיחת קבצים באפליקציה לבחירתך, העתקה/גזירה/הדבקה, שינוי שם, מחיקה,
תיקייה חדשה, חיפוש, מיון, הצגת מוסתרים, שיתוף, ופרטים. מכל קובץ או תיקייה (לחיצה ארוכה) אפשר:
הוספה למסך הבית, קיצור מותאם, שמירה בספרייה, או יצירת קובץ `.linkit` בתיקייה.
נדרשת הרשאת "גישה לכל הקבצים" (האפליקציה מבקשת בפעם הראשונה).

## שימוש כתוסף למנהלי קבצים אחרים
- **קבצי `.linkit`** - קיצור שנשמר כקובץ ונפתח מכל מנהל קבצים (פתיחה = הפעלת הקיצור).
- **ספק אחסון "LinkIt - קיצורים"** - הקיצורים מופיעים כקבצים בתוך מנהלי קבצים ובוחרי קבצים שתומכים בספקי אחסון.
- **"פתח באמצעות"** - LinkIt מופיע ברשימה בלחיצה על תיקייה בחלק ממנהלי הקבצים.
- **"שתף ← LinkIt"** - יצירת קיצור מקובץ או תיקייה (כשהאפליקציה השולחת חושפת נתיב), וגם מקישור וטקסט.
- ייצוא קיצור בודד או כל הקיצורים כקבצי `.linkit` לכל תיקייה (מתפריט האפליקציה).

## בנייה דרך GitHub
1. העלה את כל תוכן התיקייה ל-repository (כולל `.github`), תוך החלפת הקבצים הקיימים.
2. לשונית **Actions** ← הבנייה מתחילה אוטומטית (או Run workflow).
3. בסיום: **Artifacts** ← `LinkIt-APK`. חלץ את ה-APK והתקן בטלפון.

דרישות: אנדרואיד 8.0 ומעלה.
